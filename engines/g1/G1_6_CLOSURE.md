# G1.6.1 Closure Decision

G1.6.1 closes the Growth planning stage. It creates a researched, structured and
policy-validated carousel package for G2 media production. It does not render or
publish media.

## Evidence behind the closure

- G1.5 completed the observed live campaigns without pipeline crashes.
- Reserved reference copy remained protected and duplicate scores improved.
- `auto/pro-chat` and `auto/pro-reasoning` still routed to Codestral variants.
- The route experiment therefore did not provide a dependable editorial tier.
- Remaining failures were narrow: restricted product wording, causal captions,
  unsupported operational sentences, repeated CTA text and unused claim IDs.

## Frozen execution boundary

The model may research, propose three concepts, write a carousel and attempt one
bounded creative repair. Python deterministically owns:

1. Story order and product-introduction position.
2. Approved product wording and product claim IDs.
3. Walkthrough versus 7-day-trial offer policy.
4. Neutral operational language when no evidence supports causality.
5. Instagram and X copy assembled from grounded components.
6. Approved product UI and branded-end-card asset strategy.
7. Forbidden terms, duplicate copy and final readiness gates.
8. Provenance and audit persistence.
9. Seven-slide writer responses reduced to the canonical six-purpose story.

A model response that remains schema-invalid after deterministic structural
normalization receives one bounded schema-repair request. Provider outages and
invalid model output use different fallback provenance and review warnings.

Python never repairs unsupported statistics, unknown external claims, excessive
similarity or an unregistered narrative. Those remain Founder-review blockers.

## Handoff contract for G2

G2 accepts only a package with `status: ready_for_media`. It consumes slide
purpose, headline, body, visual concept, asset strategy, image queries, claim
IDs, brand specification and platform copy. G2 must not rewrite claims or CTA
copy. Any media mismatch returns to review rather than changing the G1 package.
